# Estudos de Estrutura de Dados

Repositório criado para registrar meus treinos e exercícios de Estrutura de Dados e Algoritmos em Java.

Os exercícios são básicos e feitos de forma gradual, com orientação de IA, como parte da minha preparação para entrevistas técnicas e para conseguir minha primeira oportunidade de estágio em desenvolvimento.

A ideia é usar este repositório para acompanhar minha evolução nos estudos e praticar a resolução de problemas.
